# Contributing to ThinkVertex

Thank you for being interested in ThinkVertex.

ThinkVertex is currently a small independent community project. Contributions are voluntary at this stage. There are no paid positions or salaries offered by the project.

## You do not have to do everything

A contribution does not need to be a complete feature or a finished subsystem.

Examples:

- Fix a bug
- Test an ISO
- Improve documentation
- Review code
- Suggest or research hardware
- Review a schematic
- Help with PCB design
- Improve the website
- Create graphics
- Report a reproducible problem

Small contributions matter.

## Hardware contributors

ThinkVertex is especially interested in people with experience or interest in:

- PCB design
- ARM SoCs
- DDR memory design
- Power electronics
- High-speed digital design
- Signal integrity
- Embedded Linux hardware

No contributor is expected to design an entire motherboard alone.

## Be honest about your work

Please identify work that comes from other projects and follow its license. Do not remove attribution from upstream work or claim another person's design as your own.

## Pull requests

Keep changes focused and explain what was changed and why. For hardware work, include the relevant source files and document important design decisions.

## Communication

Be respectful, constructive, and patient. ThinkVertex is a community project, and contributors may have different levels of experience.
