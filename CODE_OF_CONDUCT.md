# ThinkVertex Community Code of Conduct

ThinkVertex is intended to be a place where people can build technology together, regardless of experience level.

## Our standards

- Be respectful.
- Be constructive when reviewing work.
- Give proper credit to contributors and upstream projects.
- Do not harass, insult, threaten, or discriminate against other contributors.
- Assume good faith while still asking for evidence when technical claims need verification.
- Keep technical disagreements focused on the work.

## For project maintainers

Contributors should be treated fairly and their work should be acknowledged accurately. Participation is voluntary, and nobody should be pressured to contribute beyond what they are comfortable doing.

## Reporting problems

If someone violates these standards, report the issue privately to the project maintainer through the project's available GitHub contact methods rather than escalating the conflict publicly.

The goal is simple: build useful things, learn from mistakes, and make it possible for people to work together.
