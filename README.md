# ThinkVertex Community

**ThinkVertex** is an independent open-source community focused on building technology, software, and eventually open hardware.

## RSGL

RSGL is the community's long-term Linux and hardware project.

The goal is to build a sustainable Linux platform and, eventually, ThinkVertex-designed hardware capable of becoming a real Linux computer/console platform.

## What ThinkVertex is

ThinkVertex is currently a small, independent community project. It is not presented as a funded corporation or commercial company.

The project is being developed openly so that people who are interested can learn, contribute, test, review, and build alongside it.

## Areas of contribution

Contributions can include:

- Linux and software development
- Kernel and system work
- Hardware research and PCB design
- Hardware review and engineering feedback
- Testing
- Documentation
- Web development
- Design and graphics
- Project organization

You do **not** need to work on the entire project to contribute. A useful review, fix, test, design, or idea is valuable.

## Hardware

One of the long-term goals is an original RSGL computer platform designed as open hardware rather than simply rebranding another manufacturer's board.

Hardware development is currently in the research and architecture stage. No claim is made that a finished RSGL motherboard exists yet.

## Contributing

ThinkVertex currently operates through voluntary community contribution. There are no paid positions or salaries offered by this project at this time.

Contributors will be credited for their work, and contributions should remain transparent and properly attributed.

Before contributing, please read `CONTRIBUTING.md`.

## Principles

ThinkVertex aims to build openly and honestly:

- Credit original work.
- Respect licenses and trademarks.
- Do not present another person's work as our own.
- Document important technical decisions.
- Prefer open standards and reproducible development where practical.
- Build a community where contributors can participate without being expected to do the entire project themselves.

## Current status

ThinkVertex is a small community project under active development. RSGL is its main long-term technology project.

There is a lot left to build. That's rather the point.
